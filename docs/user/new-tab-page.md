# New tab page

> **Status:** available from 0.1.0-beta.3.

Every new tab opens on the new tab page. Its search field works like the address bar: type an address to open it, or anything else to search with your search engine. The field names the engine, for example "Search with DuckDuckGo or enter address".

After you search or open an address, Back returns from the first page to the new tab page, and Forward goes to the page again.

The address bar stays empty on the new tab page, and the cursor waits there, so you can start typing right away.
