# Downloads

> **Status:** available from 0.1.0-beta.4.

Astela saves downloads in the downloads folder of your system, without asking. If a file of the same name is there already, or a running download has the name, the new one gets a number, such as `report (1).pdf`. On Windows and macOS, names that differ only in upper and lower case count as the same name, as they do for the system. On macOS, finished downloads carry the mark of files from the internet, so the system checks them before they open the first time.

With the first download, the toolbar shows the **Downloads** button. While downloads run, a ring around it shows how far they got. The button, `Ctrl+J`, or `Command+Option+L` on macOS, opens the list of your downloads, newest first:

- A running download can be paused, resumed and canceled.
- A finished download can be opened, or shown in its folder.
- A canceled or failed download can be tried again.
- **Remove from list** takes a download off the list; its file stays.
- **Open the downloads folder** opens the folder in the file manager of your system.

Astela keeps the list for the next start; downloads that still ran when Astela quit are marked as failed.

The folder for downloads and the choice to be asked for each download come with the settings of 0.1.0-beta.5.
